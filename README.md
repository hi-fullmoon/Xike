# 息刻

> 停一刻，听见自己。

息刻是一款离线优先的个人感受日记 Android 应用。它用“内在天气”代替评判式的心情量表，用“此刻关键词”标记当下与工作、关系、身体等部分的联系。首版包含快速记录、可选的窗外地点与天气、图片附件、周期轨迹、日历回望、本地加密存储、系统身份验证应用锁，以及可导出至系统文件提供方（本地或云盘）的密码加密备份。

后续版本将优先补齐数据所有权、检索与温和的习惯支持，完整规划见 [产品 Roadmap](docs/roadmap.md)。

回望页现已支持月历/时间流切换、注脚与关键词的本地全文搜索，以及内在天气、关键词、日期和照片组合筛选；已保存的记录可继续修改内在天气、注脚、关键词、时间和照片。删除需要二次确认，并在底部提示消失前支持一次撤销；搜索索引与日记一起保存在 SQLCipher 加密数据库中，不会上传记录内容。

未完成的内在天气、文字、关键词、待选照片和补记时间会作为加密草稿保留，应用进程重建后可以继续；记录页会明确提示本机保存状态，也可在确认后完整清空草稿。需要回填过去时，可选择具体日期和时间，补记会自然进入对应日期的回望、搜索和轨迹统计。设置页可按星期和本地时间开启温和提醒、夜间勿扰或暂停一周，也可开启并选择完全离线的“每日一问”题库；提醒和每日一问默认关闭，拒绝通知权限不会影响记录等核心能力。长按桌面图标可通过“记录此刻”快捷入口直接返回记录页。

轨迹页提供内在天气分布、记录覆盖度、前一周期对比、关键词次数变化和工作日/周末对照。每个统计项都显示样本范围与限制，并可下钻到对应原始记录；本地回望文字完全在设备内生成，只有用户主动选择分享应用后才会离开息刻。

## 运行

1. 使用 Android Studio 打开本目录。
2. 确认安装 Android SDK Platform 36、Build Tools 36.1.0 和 JDK 17（Android Studio 自带的 JBR 也可以）。
3. 运行 `gradlew.bat assembleDebug`，或直接运行 `app` 配置。

应用不需要账号。日记、标签和图片索引由 Room 管理，并通过 SQLCipher 整库加密；随机数据库口令再由 Android Keystore 中不可导出的密钥封装。图片附件继续独立加密保存在应用私有目录。每条记录最多添加 9 张图片，单张上限为 20 MB；添加照片时可直接调用系统相机拍摄，拍摄结果会写入系统相册并在记录保存后生成加密副本；也可通过系统照片选择器从相册选择，无需授予全量相册权限。备份在导出前使用用户输入的密码进行 AES-GCM 加密，并包含日记中的全部图片附件。

“窗外此刻”默认不启用。只有用户主动添加时，应用才会使用一次前台粗略位置，并向 Open-Meteo 请求当前天气；经纬度不会写入草稿、日记或备份。用户也可以拒绝定位并手动输入城市。保存的城市级地点与天气快照会和日记一起进入本机加密数据库及密码加密备份，补记过去时不会自动附加今天的天气。

应用锁使用 Android 系统的面容、指纹或设备密码验证，可设置离开应用后立即、1 分钟、5 分钟或 30 分钟自动锁定。详细取舍见 [应用锁设计](docs/app-lock-design.md)。

## 发布

推送 `vMAJOR.MINOR.PATCH` 标签后，GitHub Actions 会执行测试、Lint、签名构建，并把 APK、AAB 和 SHA-256 校验文件发布到 GitHub Release。首次使用前需要配置发布签名，完整说明见 [GitHub Release 流水线](docs/github-release-pipeline.md)。
