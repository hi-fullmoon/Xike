# 位置权限与应用锁回归验证

日期：2026-10-20。

## 修复范围

- 高德配置的“测试定位”在已有精确或粗略位置权限时直接测试，不再为了检查权限重走申请流程。直接入口仍检查原有解锁／结果可处理条件，并防止重复启动尚未结束的测试；离开前台或弹框销毁时的取消逻辑保留。
- 通用 Activity Result 封装不再为 `RequestPermission`、`RequestMultiplePermissions` 或可同步返回的结果登记外部页面会话。实际权限请求仍由 AndroidX 执行，结果仍进入原有等待解锁和数据就绪的交付流程。
- 没有修改应用锁超时、Home／真实后台的 `onStop` 记录、息屏监视器、媒体与外部页面的会话策略，也不自动解锁已锁会话。正常权限弹框仅暂停再恢复 Activity，不再触发“无法观察的外部操作耗时”判断。

## 自动化验证

- JDK 17 自检、格式、180 项 JVM 测试、Lint、调试与测试 APK 构建通过；Lint 零错误、87 项警告、12 项提示。
- 新增状态机回归覆盖：未登记外部会话的权限结果不会误锁；权限返回不会清除真实后台时间或绕过立即／延时阈值；息屏后权限返回不会解锁。
- 新建独立 API 36 模拟器 `Xike_Permission_20261020`，序列号 `emulator-5562`，x86_64、1080×2400、密度 420、字体比例 1.0。仅在该无用户数据的设备上配置权限并运行测试，未改变原演示设备的权限、锁定设置、日记或 Key。
- 7 项设备用例通过：首次真实授权、真实拒绝授权、已授权的单项／多项同步返回、仅粗略权限、权限弹框中按 Home、权限弹框中实际息屏、Activity 真正停止后返回。授权与拒绝直接操作 Android 权限控制器，没有伪造权限结果；同步与正常授权未登记外部会话，立即锁定的空测试会话保持解锁。
- Home／后台用例确认真实后台时间和返回锁状态；息屏用例通过实际系统息屏事件触发生产锁屏监视器，长超时同样要求锁定。测试采用空的已解锁会话、生产状态机和真实权限页面，不读取日记、不修改应用锁偏好，不等同于生物识别或设备密码认证的端到端验收。
- 测试使用 Compose 的帧等待交付原有挂起结果；没有移除锁定结果门禁或为了测试放宽后台规则。
- 测试完成后已核对目标路径，关闭并删除本次新建的独立 AVD；原 `emulator-5560` 演示设备保持运行，权限与应用锁偏好未变。

设备用例必须显式传入 `isolatedPermissionLock=true`。首次授权、拒绝、Home、息屏用例要求无位置权限；同步用例要求精确和粗略均已授权，粗略用例仅授权粗略。设置这些状态会改变权限，只能在独立设备上执行；未传入隔离标记会跳过，不能计为通过。

```bash
adb -s "${XIKE_DEVICE_SERIAL:?请先核对独立测试设备}" shell am instrument -w -e isolatedPermissionLock true -e class com.xike.app.PermissionLockUiTest#normalGrantDoesNotLockAnImmediateSession com.xike.app.test/androidx.test.runner.AndroidJUnitRunner
```

限制：未连接真实手机，未做 API 26 的原生权限弹框验证，也没有使用伪造 Key 测试高德联网成功。高德真实定位、设备认证及厂商特有权限页面需在匹配正式 Key 的真机上继续确认。
