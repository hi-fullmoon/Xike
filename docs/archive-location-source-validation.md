# 回望地点来源展示验证

日期：2026-10-21。

## 行为

- 记录卡片仅保留原地址／温度／天气行，不显示地点来源或天气来源。原地址单行省略规则保留。
- 记录详情在原天气信息下增加地点来源，保留原地址两行显示及点击查看完整地址的交互；Open-Meteo 天气来源保留。
- 详情复用已保存的 `locationSource` 和现有中英文标签，区分高德、系统定位、手动选择；来源缺失时不增加说明、不推断历史来源。
- 沿用共享记录卡片与详情实现，仅回望详情开启来源展示；轨迹下钻保留原有显示。不修改数据、定位或备份逻辑。

## 验证

- JDK 17，180 项 JVM 测试、Lint、格式检查、调试与测试 APK 构建通过。既有模型测试覆盖三种来源、中英文标签和旧／未知来源。
- `ArchiveLocationSourceUiTest`：从真实 Open-Meteo 手动城市路径获取天气，在独立 SQLCipher 数据库写入并重新读取记录，确认生产卡片不显示两种来源，详情保留地点来源与 Open-Meteo，并可打开与关闭完整地址弹窗；中文与英文分别执行。测试只创建空正文的独立测试记录，不读取用户日记，不伪造 SDK 返回。
- API 36 独立模拟器 `emulator-5560`，1080×2400、密度 420、字体比例 1.0、浅色模式通过，并检查中英文卡片截图。
- 同一构建在 840×1800、密度 420、字体比例 2.0、深色模式下重复中英文流程通过。完成后恢复原屏幕尺寸、字体比例、浅色模式与应用语言，仅删除独立测试数据库。

限制：UI 设备测试使用真实手动城市天气；高德及系统来源复用已有标签映射并经调用路径检查，未伪造这两种定位成功。未完成真机或 API 26 验收。
