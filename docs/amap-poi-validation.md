# 高德 POI／AOI 地点显示验证

日期：2026-10-20。

## 当前行为

高德定位结果沿 `AmapLocator → amapPlaceLabels → OutdoorSnapshot` 传递地点文字。精确位置权限已授予、精度有效且不超过 100 米时，卡片地点采用“城市 · 区 · POI”；POI 为空或仅有空白时使用 AOI，再回退到原有街道。完整地址保留，若其中尚未包含选中的 POI／AOI，则追加名称，忽略大小写避免重复。

粗略权限、精度不足或无有效精度时，继续只显示行政区域，两个地址字段都不会带入 POI、AOI 或街道详情。系统定位、手动城市、天气坐标处理、定位次数与存储结构均未改动。地点语言仍由 SDK 跟随应用设置，残留中文沿原有 TinyPinyin 地区词典处理。POI 可能是附近地点，不代表已确认进入店铺，不额外调用周边搜索。
