## 修改范围

此刻页面将“管理主题”与“可多选 / 已选数量”放入主题标题右侧，取消管理按钮独占的一行。常规宽度按文字基线对齐；空间不足时自动换行，完整保留按钮和计数。

`JournalLabelChoices` 通过可选标题插槽接入此刻页面，`MomentTopicsHeader` 通过可选管理回调提供同行操作。编辑页和活动区域没有启用新插槽，继续使用原有排列。未调整主题选项、字号、配色或持久化逻辑。

## 验证结果

JDK 17.0.20.1 自检通过，以下任务通过：

```bash
./gradlew spotlessCheck testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
```

190 项 JVM 测试通过。独立 API 36 ARM64 模拟器 `emulator-5588` 上，安装同次构建的调试 APK 和测试 APK，通过真实 `MainActivity` 验证以下四种配置：

| 配置 | 主题区域检查 |
| --- | --- |
| 中文、呼吸、浅色、1080 × 2400、420 dpi、字体 1.0 | 标题与管理入口同行，计数与文字完整 |
| 英文、呼吸、浅色、同上 | 说明换行时，管理入口仍与标题对齐 |
| 英文、纸页、深色、840 × 1866（宽 320 dp）、420 dpi、字体 2.0 | 自动换行，入口和计数不被截断 |
| 中文、专注、深色、同上 | 自动换行，入口和计数不被截断 |

每种配置均通过实际点击选择主题，检查未选及已选 1 项状态，并打开管理弹窗核对入口仍可操作。已查看本次真实截图，没有注入日记或复制页面充当显示证据。
