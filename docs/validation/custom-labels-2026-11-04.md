## 已实现

- 主题与活动分别多选，提供创建、预设图标、改名、上移、下移、归档和恢复。
- 内置项保持名称与本地化规则；自定义名称保留原文，创建时校验长度、空白及同类重名。内置中文名、英文名和旧主题别名参与重名校验，结果不随当前界面语言变化。
- 目录使用稳定 ID，记录保留当时名称。改名不改写已有记录；新记录保存时使用目录当前名称。归档不删除历史关联，编辑时可保留或移除归档项。
- 此刻、日记编辑、卡片、详情、回望筛选、轨迹、本地回顾及 HTML 阅读接入主题与活动。筛选同类取任意一项，跨类型同时满足；主题筛选继续只列出记录中实际使用的项。
- 数据库版本 10，草稿版本 7，备份清单版本 10，搜索索引版本 3。迁移保留旧标签及别名，旧“运动”等标签不自动转换成活动。
- 备份包含未使用项、图标、排序、归档状态和记录引用；合并、替换和撤销同时处理目录与记录。旧版备份继续通过兼容入口读取，旧应用会拒绝新版备份。

使用本次启动的独立 API 36 ARM64 模拟器 `emulator-5584`，数据文件位于本次独立临时目录。安装、操作和仪器测试均显式指定序列号，并安装同次构建的调试 APK 和测试 APK；没有操作其他设备或清空用户环境。
