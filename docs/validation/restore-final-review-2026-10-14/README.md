# 合并恢复与撤销资格重新审核

日期：2026-10-14。

## 发现与修复

1. 冲突副本被编辑、再次导入生成后续副本，再删除前面的副本后，旧查找在编号空位处结束，会再次添加相同版本。新增单元测试先复现失败，再修正查找：新副本标识包含来源与内容版本的 SHA-256，按版本索引全部保留副本；旧 UUID 副本先按实际元数据和解密内容筛选，再重建旧标识，不在编号空位处停止。旧标识重建受原有 16 MiB 清单限制及整次导入处理预算约束，超过预算时在写入前拒绝合并，原数据不变。
2. 恢复已提交后，查询撤销资格发生异常会中断成功结果反馈。该查询现在按不可撤销处理，保留恢复成功结果，不展示未经确认的撤销动作；后续数据刷新可重新确认资格。此异常路径进行了代码审核，未进行存储故障注入。

不同标识的独立记录仍保留，即使内容一致，也不会仅凭内容被合并。新增测试包括删除多个旧编号位置、只剩后续副本、旧 UUID 副本存在编号缺口，以及内容一致但来源不同的 UUID v3 记录。
