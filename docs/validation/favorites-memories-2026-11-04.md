## 实际界面与跨进程

`JournalFavoritesMemoriesUiTest` 通过真实 `MainActivity` 的心情选择和原生日期选择器保存两条补记，分别对应一个月前和上一年同月同日，再执行以下操作：

- 打开往日日期分组及当天列表，打开详情并收藏。往日详情没有编辑入口。
- Activity 重建后仍显示已收藏，使用独立仪器进程读取数据库确认收藏。
- 返回回望，启用“仅看收藏”，打开对应记录；取消收藏后详情仍可见，关闭后显示条件空状态，清除收藏筛选可操作。
- 再启动独立仪器进程，确认取消收藏已保存且原两条记录仍存在。

API 26 和 API 36 的常规中文录入、收藏、取消和新进程读回均通过。实际显示检查覆盖：

## 限制

- 未覆盖真机、所有主色、接近上限的媒体备份或超大日记库，不把模拟器结果扩写为全面发布验收。
- 日期运算、闰日和夏令时边界有 JVM／真实数据库回归；尚未实测保持页面跨午夜或在系统时区切换瞬间的完整刷新链路。代码使用前台生命周期内的日期检测及系统广播，恢复前台时重新读取。
- 本轮未重跑完整设备 UI 套件。此前两个天气组件用例的既有失败见[前序验证](custom-labels-2026-11-04.md)。

- 英文窄屏两倍字体截图中，原有回望日期行及底部导航仍可见换行／截断；这些区域未在本次改动范围内处理，不将其列为显示验收通过项。
