# 1.6.0 发布前验证

日期：2026-11-10。目标版本 `v1.6.0`，Android `versionName=1.6.0`、`versionCode=1006001`，最低 API 26、目标 API 36。

## 候选内容

应用功能代码为 `b04a160`，测试兼容提交为 `5e6a11a`；后续发布记录提交仅修改文档。相对公开版本 `v1.5.4`，本次包含收藏与往日回望、记录图片与正文对齐、移除主题和活动入口并保留历史数据，以及可选 AI 回顾。

数据库由 schema 9 经 9→10→11 升级；新备份版本为 11。旧备份可继续导入，包含收藏状态的新备份需由支持该格式的版本读取。

## 本地构建

JDK 17.0.21 环境下，以下与正式发布相同的门禁通过：

```bash
XIKE_VERSION_NAME=1.6.0 XIKE_VERSION_CODE=1006001 ./gradlew spotlessCheck test lint
```

Debug 和 Release 分别运行 203 项 JVM 测试，均无失败、错误或跳过。调试 APK 和设备测试 APK 也已构建。

## 验证边界与回滚

- 尚未调用真实 AI 服务；已验证本地预览、加密配置、发送前置条件及取消处理。分析结果布局和响应期间的滚动检查使用了用户批准的临时 Mock，Mock 不在发布代码中。
- 本轮不是全套真机验收，未完成所有风格、语言、字号组合，以及录音 5 分钟上限、超大视频和大规模归档检查。相关结果不扩大为全部设备或媒体组合通过。
- 正式包覆盖升级的具体样本与结果以发布页为准；迁移、媒体和备份定向检查不扩大为所有真实历史数据的覆盖升级验收。
- 回滚由仓库维护者决定。若出现数据丢失、加密绕过或 P0／P1 问题，停止推广该版本，优先发布保留 schema 11 兼容性的修复版本；不以卸载、清空数据或强制安装旧数据库版本处理。
