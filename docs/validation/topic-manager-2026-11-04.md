## 最终界面

- 主题按图标、名称和内置/自定义标识排列；自定义主题可点击编辑，次要操作收进每项右侧的菜单。
- 使用中、已归档分区分别浏览，切换后返回列表顶部；常规字号使用分段控件，大字体使用自动换行的完整标签，避免拆开英文单词。
- 归档项直接提供恢复按钮。排序通过独立模式进行，仅在排序时显示上下箭头，首尾不可移动的方向禁用。
- 底部固定新增主题入口；右上角关闭按钮明确标为“关闭主题管理”，与保存提示的关闭操作区分。
- 新增、编辑复用原有名称和图标表单，主题列表与表单分别显示；取消新增返回原分区，保存后定位到对应主题。空列表仍保留可操作的新增入口。
- 长名称完整换行，图标和操作保持在行首，列表内容可滚动；窄屏大字体下底部操作纵向排列。

修改集中在主题管理弹窗及共用表单的提取。此刻和日记编辑中的主题管理使用新版，活动管理列表继续使用原布局；未改动日记、目录 ID、加密、数据库结构或备份格式，也没有自动调整已有目录。

## 构建与测试

JDK 17.0.20.1 自检通过，以下任务通过：

```bash
./gradlew spotlessCheck testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
```

190 项 JVM 测试通过。最终独立 API 36 ARM64 模拟器 `emulator-5594` 上，安装同次构建的调试和测试 APK，完成 11 次真实 `MainActivity` 仪器测试检查：

1. 初始目录管理与重启读回：恢复、归档、排序及持久结果一致。
2. 通过真实界面创建自定义主题、24 字名称主题和活动，保留草稿。
3. 上下移动后恢复原顺序；从归档分区新增后取消，仍返回归档分区，草稿不变。
4. 四组实际显示检查，均打开菜单、进入编辑并核对键盘上方的保存操作。
5. 新进程保存记录、改名、归档与搜索，核对备份替换、合并和撤销，再由独立进程读回结果。
6. 英文窄屏大字体下归档全部使用中主题，检查空列表新增入口仍可操作，再创建主题；原记录内容保持一致。
