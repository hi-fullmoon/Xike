# 最小发布检查清单

每次候选版本在创建标签前完成本清单。自动化结果需要链接到对应的 GitHub Actions 运行记录，手工烟测需要记录设备、Android 版本、安装包 SHA-256 和测试人。

## 自动化门禁

- [ ] `./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest` 通过。
- [ ] 数据库 schema 已导出，迁移测试覆盖当前公开版本到候选版本。
- [ ] 工作区无意外生成文件，候选提交与准备打标签的提交一致。

## 核心烟测

- [ ] 全新安装后首次启动正常，无账号或网络依赖。
- [ ] 分别保存无文字记录、280 字记录和同一天多条记录，重启后内容一致。
- [ ] 保存含 1 张和 9 张图片的记录，缩略图与全屏查看均可读取。
- [ ] 首次拒绝和允许麦克风权限分别验证；录制、暂停、继续、试听、后台自动收尾和 5 分钟上限行为正常。
- [ ] 保存含语音的记录，重启后可播放；编辑移除、删除撤销及撤销期限结束后的文件清理正确。
- [ ] 开启应用锁，验证立即、1 分钟和后台最近任务缩略图保护；关闭后可正常进入。
- [ ] 在图片／视频选择器中跳转其他应用，超过锁定时限后返回或取消：先认证，后交付待处理结果；短于非立即时限的返回保持连续性。无法观察的选择器按启动耗时保守判断，确认“立即”模式的返回认证。
- [ ] 导出含多图和语音记录的加密备份，确认系统文件提供方收到非空 `.xike` 文件。
- [ ] 关闭加密导出 `.zip`，解压后打开 `index.html`，确认文字、图片、天气和录音可离线浏览，且页面无法执行日记中的 HTML/脚本。
- [ ] 使用正确密码查看备份摘要，默认合并恢复后保留本机新增记录，补入缺失记录，图片与语音完整。
- [ ] 同一标识的冲突记录保留双方版本；重复导入加密及未加密备份均不新增相同版本或重复附件。
- [ ] 选择“替换全部内容”并再次确认后，仅保留备份记录；撤销后恢复此前本机记录和附件。
- [ ] 从未加密 `.zip` 查看摘要并恢复，确认无需密码、附件完整；缺少附件或结束标记时不得替换本机内容。
- [ ] 恢复后执行一次撤销，确认设备原内容恢复且撤销入口消失。
- [ ] 恢复后分别新增、编辑、删除及撤销删除，确认恢复撤销入口和快照失效；重启及旧撤销操作不得覆盖后续记录。失败写入、草稿及外观修改不使资格失效。
- [ ] 使用错误密码和截断备份恢复，确认设备原记录与图片不变。

## 升级与发布

- [ ] 从当前公开版本覆盖安装候选版本，记录、图片、主题和应用锁设置保留，数据库自动升级到 schema 9，验证 8→9 迁移及可空的地点来源字段；旧快照来源保持未知，已有历史迁移覆盖继续保留。
- [ ] 设置页展示的版本号与 APK/AAB 的 `versionName` 一致。
- [ ] API 26 和目标 API 设备至少各完成一次核心烟测。
- [ ] 签名 APK 与 AAB 校验通过，SHA-256 文件与实际产物一致。
- [ ] 已准备发布说明、已知问题和回滚决定人；发现数据丢失、加密绕过或 P0/P1 缺陷时停止发布。
