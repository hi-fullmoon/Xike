# 备份格式与离线阅读

导出时默认开启“使用密码加密”。开启后得到 `.xike` 文件，关闭后得到普通 `.zip` 文件。两种文件都包含同一份日记清单、媒体文件和静态 `index.html`，但 `.xike` 整体用密码派生密钥和 AES-GCM 加密，浏览器无法直接打开其中的页面。

未加密备份是单个 ZIP 文件。解压后打开根目录的 `index.html`，即可离线阅读文字、心情、主题、天气、照片和录音；媒体路径相对于页面，不依赖应用、账号或网络。常见 JPEG、PNG、GIF、WebP 照片保留可识别的扩展名；浏览器不支持的媒体格式仍保存在 ZIP 中，但可能无法内嵌预览。页面不执行脚本，日记文字按 HTML 文本转义。未加密 ZIP 和解压目录中的全部内容都是明文。

归档清单 `manifest.json` 是应用恢复的数据源，`index.html` 仅用于阅读。版本 7 的归档包含 `manifest.json`、`index.html`、`images/` 与 `audios/` 下实际引用的附件，以及最后的 `complete.txt`。恢复前会识别加密与否，检查格式版本、每项大小、ZIP CRC、结束标记、图片和录音是否齐全，然后展示摘要并要求确认替换。替换前的本机数据仍会生成加密撤销快照。版本 4–6 的加密归档及更早的加密 JSON 备份继续可导入。

`.zip` 适合希望保存一份可读副本的用户；`.xike` 适合保存到共享设备或云盘。解压后的 HTML 不是加密文件，不能把它与加密备份混为一谈。若以后需要“浏览器输入密码直接打开单个文件”，那会是另一种带客户端解密器的格式，需要单独评估兼容性与安全性。
